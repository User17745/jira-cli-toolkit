# Project identity

The public display name is **CLI Toolkit for Jira**. CLI Toolkit is the project identity; “for Jira” describes compatibility. Use the toolkit’s original terminal icon and artwork. Do not incorporate Atlassian or Jira logos into the project identity or promotional covers.

Installation actions say **Install the CLI**. The executable remains `jira`; the repository remains `jira-cli-toolkit`. Command examples and existing installation/configuration paths retain their technical names for compatibility. This preserves the user-requested executable without presenting Jira as our own product wordmark.

The website and README identify the project as independent and include this notice:

> Independent project. Not affiliated with, endorsed by, or sponsored by Atlassian. Jira is a trademark of Atlassian.

This follows the naming and differentiation principles in [Atlassian’s trademark guidelines](https://www.atlassian.com/legal/trademark). These changes address confusing presentation; they do not certify legal clearance of every identifier or use. Recheck the published guidance before changing public branding. The earlier supplied logo-bearing cover is removed from the current published source; Git history and the original user file are preserved.
