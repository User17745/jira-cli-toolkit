## What's new in 2.6

- **`jira api --paginate`** follows Jira's page protocols (offset, cursor and Service Management) and prints one merged JSON result, with `--max-items` and loop protection. GET, plus POST for issue search.
- **Service desk commands:** `jira desk list | queues | queue` and `jira request list | view | comment | transitions | transition`, with `--internal` for agent-only notes and ID, key or name lookup for desks and queues.
- **A bundled agent skill:** `jira skill install` writes a `SKILL.md` for Claude Code (or any agent with `--path`) that matches the installed commands; `jira skill show` prints it.
- **winget-aware updates:** `jira update` recognizes a winget installation and gives the `winget upgrade` command instead of replacing the file.
- Issue templates on GitHub for bug reports and feature requests.
